# Ruled Surface Example Meshes

This folder contains small demo meshes for ruled-surface tasks and polishing demos.

Files:

- `hyperbolic_paraboloid_patch.obj`
  - A saddle-shaped hyperbolic paraboloid patch.
  - Sampled from `z = 0.7 x y`, `x,y in [-0.4, 0.4]`.
  - Useful for showing a doubly ruled surface.

- `cylindrical_patch.obj`
  - A cylindrical ruled patch sampled from a short cylinder segment.
  - Useful for cooperative polishing demos over tank-, pipe-, and roller-like workpieces.

All meshes are lightweight OBJ files with triangles and UVs only, so they are easy to import into viewers or use as simple demo assets.
